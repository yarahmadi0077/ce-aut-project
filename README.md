# Fly Fighter Plane

This repository contains the **Final Term Project** for the Basic Programming course of the Computer Engineering Department at Amirkabir University of Technology (AUT). The project, titled **"Fly Fighter Plane"**, was developed under the supervision of Dr. Hossein Zeinali.

---

## Project Description
**Fly Fighter Plane** is a console-based game that simulates a fighter plane navigating through obstacles. The primary goal is to avoid collisions and score points by surviving as long as possible. This project demonstrates key programming concepts such as loops, conditionals, and basic game logic.

---

## Features
- **Real-time Gameplay:** Players control the plane using keyboard inputs.
- **Obstacle Generation:** Randomized obstacles appear at increasing difficulty levels.
- **Score Tracking:** A scoring system rewards players based on survival time.
- **Game Over Mechanism:** The game ends when the plane collides with an obstacle.

---

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/yarahmadi0077/Fly-Fighter-Plane.git
   cd Fly-Fighter-Plane
   ```

2. Compile and run the program:
   - If the program is written in **C++**, use the following commands:
     ```bash
     g++ main.cpp -o fly_fighter_plane
     ./fly_fighter_plane
     ```
   - If the program is written in **Python**, use:
     ```bash
     python3 main.py
     ```

3. Follow the on-screen instructions to play the game.
